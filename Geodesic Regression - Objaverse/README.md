To run the training codes, you can use :
python trainUDFPointCloud.py -n 10 -bs 3072

This is used to run the training codes for 10 epoch with batch size of 3072.

Meanwhile for testing, you can check the jupyter notebook file : testobjaverseerror.ipynb and run this.

The environment used in this the training & testing process are the same as the other environment in this repository. As mentioned in the General Readme files, you can install the environment from create_env_UDFGeod.sh file.
